# UI Mocks

Store every image used to generate implementation code in the repository-root `ui-mocks/` folder. Copy the source image there before or alongside the generated implementation so it remains available after temporary tool files are removed.

## Naming

Use this filename format:

```text
YYYYMMDD-name-of-design.ext
```

- `YYYYMMDD` is the date the image is added to the repository.
- `name-of-design` is a concise, lowercase, kebab-case description.
- Preserve the source image extension.

For example: `20260820-core-app-shell.png`.

Reference the repository copy from design QA reports and implementation notes. Do not link to temporary `.codex` image paths.
